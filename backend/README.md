# Backend API (ASP.NET Core)

Это серверная часть приложения, разработанная на платформе **.NET 8** с использованием **ASP.NET Core Web API**.

## Локальный запуск (Local Development)

Выполните следующие шаги для настройки и запуска проекта на вашем локальном компьютере.

### 1. Требования (Prerequisites)
Убедитесь, что на вашем компьютере установлены:
* **.NET 8 SDK** (версия 8.0 или выше)
* IDE / Редактор: **Visual Studio 2022**, **JetBrains Rider** или **VS Code** (с расширением C# Dev Kit)

### 2. Переход в директорию бэкенда
Если вы находитесь в корне репозитория, перейдите в папку проекта:
```bash
cd backend
```

### 3. Восстановление зависимостей (NuGet)
Загрузите все необходимые NuGet-пакеты (включая Swashbuckle для работы Swagger):
```bash
dotnet restore
```

### 4. Запуск приложения
Запустите проект в режиме разработки с поддержкой автоматической перезагрузки кода (hot-reload). Вы можете выбрать один из встроенных профилей:

**Запуск по протоколу HTTPS (рекомендуется):**
```bash
dotnet watch run --launch-profile https
```

**Запуск по протоколу HTTP:**
```bash
dotnet watch run --launch-profile http
```

*Если в этой директории находится несколько проектов, укажите путь к конкретному `.csproj` файлу:*
```bash
dotnet watch run --project ИмяПроекта.csproj --launch-profile https
```

### 5. Локальные адреса и Swagger UI
Приложение настроено на запуск в окружении `Development` и автоматически откроет браузер при старте. 

В зависимости от выбранного профиля API будет доступно по следующим адресам:

* **Профиль HTTPS:**
  * Домашняя страница: `https://localhost:7115`
  * Документация **Swagger UI**: `https://localhost:7115/swagger`

* **Профиль HTTP:**
  * Домашняя страница: `http://localhost:5216`
  * Документация **Swagger UI**: `http://localhost:5216/swagger`
